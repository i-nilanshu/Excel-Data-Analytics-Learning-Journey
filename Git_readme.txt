Excel Data Analytics Learning Journey

Overview

This repository documents my hands-on learning journey in **Microsoft Excel as part of my broader Data Analytics with Generative AI learning path**.

The workbook contains multiple worksheets covering Excel fundamentals, formula practice, data handling, lookup and reference functions, logical and date-time calculations, statistical functions, and sample datasets for inventory and order analysis.

My objective is to strengthen my ability to transform raw data into clean, structured information, analyse it using Excel, and communicate useful insights through reports.

Sample Data Analysis
The workbook contains practice datasets for student performance, product inventory and order analysis.

Student Performance Analysis

The student marksheet contains 15 student records across six subjects.

Key observations from the sample:
- Average student percentage: approximately 80.77%
- Highest scorer: Ishita, with 569 out of 600
- Lowest scorer: Rohan, with 394 out of 600
- Computer has the highest subject-wise aggregate marks in the sample.

Inventory Analysis

The product inventory dataset contains seven products.

Key observations:
- Total units in stock: 124
- Total inventory value: ₹223,476
- The Monitor 24 Inch has the highest inventory value in the sample.

Inventory value is calculated as:

`Inventory Value = Unit Price × Quantity`

Order and Sales Analysis

The sample order dataset contains 25 transactions from January to March 2026.

Key observations:
- Gross sales: ₹171,000
- Total quantity: 187
- Discount-adjusted sales: ₹156,965
- West is the highest-selling region in the sample.
- Furniture is the highest-selling category in the sample.
- February has the highest sales among the three months.

Discount-adjusted sales are calculated as:

`Net Sales = Sales × (1 − Discount)`

Note: These are observations from a sample practice dataset and should not be interpreted as real business performance.
